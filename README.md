# Ecommerc

Planning repository for the AI Commerce Marketplace Platform.

Current scope:

- `docs/`: architecture, module design, API drafts and implementation plan.
- `commerce-admin/`: React/Vite admin CMS, to be scaffolded.
- `commerce-ai-platform/`: NestJS AI service, to be scaffolded.
- `commerce-core-service/`: Java core-service contract only for now.
- `commerce-platform-infra/`: Docker local infrastructure, to be scaffolded.

Core Java implementation is intentionally left for the Java backend owner. This repo currently documents the service responsibilities and contracts.
